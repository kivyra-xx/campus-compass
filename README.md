# Campus Compass

A fictional university portal demo for Meridian Coast University, built with React, TypeScript, and Vite.

## Run locally

```sh
npm ci
npm run dev
```

## Publish a GitHub Pages preview

The deployment workflow publishes the `main` branch to:

`https://kivyra-xx.github.io/campus-compass/`

Create a GitHub repository named `campus-compass`, push this project to its `main` branch, then set the repository's **Settings → Pages → Build and deployment source** to **GitHub Actions**. The workflow builds and deploys the site on each push.

The demo contains fictional accounts and records only. Do not commit `.env` files, real student information, or secret keys.
